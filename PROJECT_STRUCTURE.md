## Component Responsibilities

### main.py
- CLI interface for pipeline execution
- Argument parsing (--phases, --url, --output)
- Configuration loading and validation
- Orchestrator instantiation and execution

### config.py
- Loads .env configuration
- Dataclass definitions for all config sections
- Validation of required fields
- Global config instance

### phase1_ingest.py
- Downloads video from URL (yt-dlp)
- Detects scene breaks automatically
- Extracts dense content windows
- Outputs: video file + scene metadata

### phase2_analysis.py
- Sends video to Qwen 3.7-max API
- Parses narration into timestamped segments
- Handles multimodal (video+audio) input
- Outputs: narration segments JSON

### phase3_tts.py
- Generates speech from text (Qwen 3-TTS-Flash)
- Applies voice configuration (Sweet Tea, drama tension)
- Time-stretches audio to prevent desync
- Outputs: aligned WAV files

### phase4_upscale.py
- Upscales video frames to 4K
- Applies LUT color grading (Sunset preset)
- Applies CAS sharpening
- CPU mode ready, GPU-optimized
- Outputs: upscale config (video processing deferred to GPU)

### phase5_captions.py
- Generates captions with word-level timestamps
- WhisperX (primary) + faster-whisper (fallback)
- Exports SRT and WebVTT formats
- Outputs: subtitle files

### orchestrator.py
- Chains all phases together
- Error handling and recovery
- Execution logging
- Supports full and partial pipeline execution

## Data Flow

```
User Input (.env)
    ↓
Phase 1: YouTube URL → Video File
    ↓
Phase 2: Video File → Narration Segments
    ↓
Phase 3: Segments → TTS Audio + Timing
    ↓
Phase 4: Video + LUT → Upscaled 4K
    ↓
Phase 5: Audio → Captions (SRT/VTT)
    ↓
Outputs: Audio + Video + Captions + Metadata
```

## Technology Stack

| Component | Technology | Purpose |
|-----------|-----------|---------|
| **Download** | yt-dlp | YouTube/platform video downloads |
| **Scene Detection** | PySceneDetect | Automatic scene break detection |
| **Multimodal Analysis** | Qwen 3.7-max (DashScope API) | Video → narration generation |
| **TTS** | Qwen 3-TTS-Flash (DashScope API) | Text → speech synthesis |
| **Audio Processing** | Librosa | Time-stretching for sync |
| **Upscaling** | Real-ESRGAN (framework) | 4K upscaling |
| **Color Grading** | LUT (.cube files) | Professional color presets |
| **Captions** | WhisperX / faster-whisper | Speech-to-text with timestamps |
| **Orchestration** | Python async/sync | Pipeline coordination |

## Running the Pipeline

### Full Pipeline
```bash
python main.py
```
Executes: 1 → 2 → 3 → 4 → 5

### Custom Phases
```bash
python main.py --phases 1,2,3
```
Skips: 4, 5

### With Overrides
```bash
python main.py --phases 1,2 --url "https://..." --output ./results
```

## Extensibility

### Add New Voice
1. Update `voice_and_preset_config.json`
2. Set VOICE_ID in .env
3. Phase 3 automatically applies in API call

### Add New LUT Preset
1. Save .cube file to project root
2. Update `voice_and_preset_config.json`
3. Set LUT_FILE in .env
4. Phase 4 automatically applies

### Customize Narration Prompt
1. Edit `phase2_analysis.py`
2. Modify `prompt` variable in `analyze_video()`
3. Rerurn Phase 2

### Switch to Different Model
1. Update ANALYSIS_MODEL or TTS_MODEL in .env
2. Ensure model available on DashScope API
3. Restart pipeline

## Error Handling

- Phase failures are logged with full stack traces
- Execution log includes all errors
- Pipeline continues if non-critical phase fails
- Retry logic available in phase implementations
